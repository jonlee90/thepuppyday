## How to Use This Template

### Step 1: Pick your blog post from the table above

### Step 2: Copy the prompt template below

### Step 3: Replace each `{{PLACEHOLDER}}` with the values from your row

The placeholders are:
- `{{TOPIC_TITLE}}` -- The blog post title
- `{{TARGET_KEYWORDS}}` -- Comma-separated target keywords
- `{{WORD_COUNT}}` -- Target word count range
- `{{ANGLE}}` -- The specific angle and talking points for this post
- `{{INTERNAL_LINKS}}` -- Links to include naturally within the article
- `{{FAQ_QUESTIONS}}` -- The 3 FAQ questions for the end of the article

### Step 4: Open Perplexity Pro and select "Writing" focus mode

Writing mode generates content from the model without injecting web search citations into the text. This produces cleaner, more natural-sounding blog content. If you want Perplexity to research facts first, run a separate Pro Search query for the topic, then use Writing mode for the actual draft.

### Step 5: Paste the filled-in prompt and submit

### Step 6: Review the output

Check for:
- Any banned phrases that slipped through (search for words like "delve", "crucial", "landscape")
- Natural keyword placement (not stuffed)
- Accurate pricing and service details
- Working internal link paths
- Word count is within target range
- FAQ answers are concise (40-60 words each, good for featured snippets)

## Tips for Best Results

1. **Use Writing mode in Perplexity Pro.** This generates content without injecting web citations into the text, producing cleaner blog content. If you need to research facts first (pricing in other salons, breed-specific data, local park details), run a separate Pro Search query and reference those facts when reviewing the output.

2. **Run one post at a time.** Do not try to generate multiple posts in one prompt. Each post deserves a fresh context window.

3. **Review for banned phrases.** Even with explicit instructions, AI will occasionally slip in a banned word. Do a quick Ctrl+F for "delve", "crucial", "landscape", "it's important", "whether you're" before publishing.

4. **Add your own anecdotes.** The prompt asks Perplexity to generate anecdotes, but replacing them with real stories from your grooming experience will make the content significantly more authentic. Even one real story per post makes a difference.

5. **Verify pricing and local details.** Double-check that any pricing mentioned matches your current rates and that any local references (parks, addresses, neighborhoods) are accurate.

6. **Adjust word count if needed.** If the output runs long, cut from the middle sections, not the opening or FAQ. The opening and FAQ are the highest-value SEO sections.

7. **Post-generation editing pass.** After Perplexity generates the draft, read it out loud. If any sentence sounds like something you would never actually say to a customer, rewrite it in your own words. This 10-minute pass is the single biggest factor in making AI content rank well.
